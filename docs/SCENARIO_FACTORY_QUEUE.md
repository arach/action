# Scenario Factory Queue

Small scenario at-bats for the Action/Mira source-material factory. Editorial
intent lives here because the current scenario schema is intentionally compact.

## Talkie Source Review

- `talkie-source-review-short`: shortest useful pass from workflow selection to viewer entry.
- `talkie-source-review-medium`: comparison pass that shows switching and one compacting gesture.
- `talkie-source-review-long`: fuller review pass with switching, detail compression, and viewer entry.

## Preframe Source Material

- `preframe-source-material-short`: catalog open plus one source asset selection.
- `preframe-source-material-medium`: catalog to queue to preview, useful for intake review.
- `preframe-source-material-long`: catalog, frames, FX, prompt, and preview in one deliberate pass.
